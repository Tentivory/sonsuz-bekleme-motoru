## Dünyanın En Devrimci, En Absürt ve En İşe Yaramaz Projesi

- **%100 Çalışır**: Gerçekten sonsuz döngüye girer. Test edildi, evrenin ısı ölümüne kadar sürer.

- **Rastgele Absürtlük**: Her saniye farklı bir varoluşsal kriz üretir.

### 🚀 Nasıl Çalıştırılır?

```bash
git clone https://github.com/Tentivory/sonsuz-bekleme-motoru.git
cd sonsuz-bekleme-motoru
python3 bekleme_motoru.py
```

Sonra otur ve izle. Hayatın anlamı belki bu sefer gelir. Gelmezse de sorun değil, motor hala bekliyor.
